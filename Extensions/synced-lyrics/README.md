# 同步歌词（SuperIsland Extension）

在 SuperIsland 中显示当前播放歌曲的逐行与逐字同步歌词。

构建 29 提供原版与 14 种新增完整播放器场景。效果总览和各样式截图见
[项目介绍](../../README.md#播放器样式) 与 [截图图鉴](../../docs/GALLERY.md#播放器图鉴)。

## 功能

- 支持 SuperIsland 能识别的 Apple Music、Spotify、浏览器及其他媒体应用
- QQ 音乐优先匹配同平台、同专辑的歌词；其他播放器或服务不可用时使用酷狗备用源，交叉比较多个时间轴以避开异常候选
- 紧凑视图显示当前歌词
- 原版布局采用左侧封面／实时音频频谱与进度，右侧标题、歌词和原生播放控制；封面上限 140 点
- 原版歌名和歌手同一行，完整视图显示四行歌词；其余 14 种样式独立组合整窗歌词、封面、背景与胶囊控制条
- 从封面提取明亮饱和的主色、辅助色和高亮色，整座岛的背景渐变随切歌平滑过渡；黑白封面保持中性色
- 完整视图默认 240 点高，可调整为 200–300 点；普通展开保留紧凑布局
- 歌词、时间和进度条共用宿主的播放时钟；中途打开、暂停恢复、倍速、拖动和重新展开均持续同步
- 点击任意一句歌词跳转到对应位置；当前句按 LRC 时间高亮（不使用没有逐字数据的模拟扫色）
- 支持上一首、播放暂停、下一首；封面下方的频谱通过 macOS 14.2+ 的 Core Audio 进程音频 Tap（14.0–14.1 使用 ScreenCaptureKit）读取当前播放器的真实 PCM 并做 FFT，绘制 56 根细密的底部对齐频谱柱，静音和暂停时归零
- 使用本地 OpenCC 将歌词转换为简体，不影响歌词时间轴
- 播放时自动将歌词岛置前，也可以在设置中关闭
- 默认无固定提前量；播放时间旁的校准按钮可提前、延后或重置本曲偏移，调整单独记忆
- 歌词绑定歌曲标题、歌手和播放器，切歌立即隐藏旧词；旧请求不能覆盖新歌
- 缓存最近 16 首歌曲歌词，校验匹配信息并清理旧版缓存
- 自动清理 `Official Video`、`MV`、`Lyrics` 等视频标题后缀

## 安装

本仓库构建时已将 `Extensions/synced-lyrics` 打包。手动安装时，将整个
`synced-lyrics` 文件夹复制到（不要和旧版 `lyrics-island` 重复安装）：

```text
~/Library/Application Support/SuperIsland/Extensions/
```

然后打开 SuperIsland 设置，在 Extensions 中启用“同步歌词”。

宿主与扩展都需要使用本仓库版本。若本机安装目录中存在旧版副本，请先在设置里核对版本。

0.11.0 使用定制宿主新增的 `View.nowPlayingLyrics` 原生视图，需要同时更新本仓库中的
SuperIsland 宿主，不能只将扩展复制到旧版应用。旧版默认高度会自动迁移为 240 点。

修改源码后运行 `./build.sh` 重新生成 `bundle.js`。简体转换由随扩展打包的
[opencc-js](https://github.com/nk2028/opencc-js) 提供。

如果浏览器中的音乐无法被识别，请在 SuperIsland 的 Now Playing 设置中开启浏览器媒体检测，并按提示授予自动化权限。

## 实时音频频谱

第一次点击封面下的“启用音频频谱”，按 macOS 提示允许屏幕与系统音频录制。
授权后只注册当前播放器的音频输出，不注册视频输出，不采集麦克风，也不录制或上传。
拒绝授权或播放器无法采集时不会显示假动画。关闭歌词界面或暂停会停止采集。

技术依据：[Apple ScreenCaptureKit 示例](https://developer.apple.com/documentation/screencapturekit/capturing-screen-content-in-macos)。

## 数据来源

QQ 音乐播放时优先使用[QQ 音乐](https://y.qq.com/)的搜索和歌词接口，其他情况使用[酷狗音乐](https://www.kugou.com/)的歌词搜索和下载接口。本扩展不会内置或分发歌词内容；缓存只保存在用户本机的 SuperIsland 扩展存储中。

QQ 音乐优先读取同一录音版本的 QRC 逐字时间，失败时保留同一歌曲的 LRC。逐字解码使用 MIT 许可的 qrc-decoder 1.0.2 与 pako 2.1.0，许可证随 vendor 目录附带。第 29 版宿主可在“歌词样式与校准”中选择“原版”四行歌词布局，或 14 种完整的原生播放器场景。新场景同时改变封面、歌曲/专辑信息、歌词构图、底部胶囊控制条和整窗背景；复杂 GPU/3D 场景按小窗轻量改编，样式与偏移分别保存。顶部自动隐藏工具栏只在歌词页启用，其他扩展仍保留固定工具栏及其占位。

新增场景播放时，鼠标离开窗口后控制胶囊简化为细进度线，移入、暂停、拖动或打开校准时恢复；进度线位置保持固定。右上角不显示特效名称。逐字起伏与高亮使用 QRC 的真实时间，镜台、时计、绘光等提供整场景原生动效。

第 29 版将歌词滚动与装饰动画分开：换行只移动文字，边框和时计齿轮不会重新出现；右上角频谱已移除。镜台使用更明亮的专辑色，莫奈背景完全不透明，静止使用原版专辑渐变。随包媒体适配器更新到 v0.7.5，修复跳转命令提前退出导致只更新界面进度的问题。
