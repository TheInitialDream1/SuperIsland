# 原生刘海扩展

在「设置 → 扩展」启用想用的工具。展开刘海后，点顶部对应的图标进入该工具的面板。也可以从扩展详情点「在刘海中打开」。停用后，工具从标签栏移除，已经保存的内容会在下次启用时继续显示。

- **剪贴板历史**左侧查看、搜索和筛选记录，右侧预览文字、链接、图片和文件，并可复制、置顶或删除选中项。启用扩展后，可以单独开启或暂停「记录剪贴板历史」。记录从下一次复制开始，数据保存在本机。设置中可调整保留天数。停用扩展会暂停记录。
- **随手便签、本地待办、每日一句**分别保存本机笔记、任务和语录。可直接在各自的面板中编辑。
- **倒计时**可开始、暂停、继续和重置。计时以结束时间为准，收起刘海后继续计时。
- **系统状态**显示 CPU 占用与空闲、已用及压缩内存、已用交换内存、磁盘剩余及已用容量、本机电源和温控。电量以圆环和百分比显示，耳机有上报时会分别显示左右耳和充电盒。
- **时钟、时间进度、刘海伙伴**分别显示本地时间、当天及本周进度，以及 SuperIsland 的伙伴。
- **同步歌词与置物架**沿用原有面板。同步歌词在扩展设置中管理，置物架在模块设置中管理。

「设置 → 外观 → 背景不透明度」统一调节刘海背景（78–100%）。文字、按钮和封面保持原有不透明度。莫奈歌词场景、紧凑状态下的实体刘海和系统「降低透明度」继续使用实色。
